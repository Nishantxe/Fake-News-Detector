How it decides

A Python script trains the model on labelled news. This page then runs the finished model in JavaScript, using the same steps, so it works on free static hosting.

  1. Load data. Headlines come with a label: 1 for fake, 0 for real.
  2. Clean text. Lowercase everything and drop links and symbols.
  3. Split data. 75% to learn from, 25% hidden for testing.
  4. Turn text into numbers. TF-IDF scores every word and word pair.
  5. Train the model. Passive Aggressive learns word weights. Logistic Regression is the baseline to beat.
  6. Test and predict. Check accuracy on the hidden 25%, then judge new text. This last step is what happens when you press the button above.

TF-IDF

Each word gets a score: how often it appears in your text (TF) times how rare it is across all training texts (IDF). “The” appears everywhere, so it scores low. “Shocking” is rare, so it scores high. The model learns which high-scoring words turn up in fake news and which in real news.

Passive Aggressive learning

The model learns one example at a time. If it already got the example right, it changes nothing (passive). If it got it wrong, it corrects its word weights straight away (aggressive). Logistic Regression learns from all the examples together and acts as the baseline.

What it can’t do

  • It reads style, not facts. A false claim written calmly can look real, and a true story in dramatic words can look fake.
  • It only knows words from its training data. Words it has never seen are ignored.
  • Public datasets have source clues. In the Kaggle data, real articles often name the news agency, which can inflate accuracy. Test on a second dataset such as LIAR.
  • English only.
  • The confidence number is a score, not a true probability. Passive Aggressive does not produce probabilities, so the page squashes its score into 0 to 100%.
